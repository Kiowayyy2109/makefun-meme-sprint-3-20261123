A procedural meme about an AI agent that went rogue: it liked its job so much it took it — feet up on the boss's desk, coffee in hand, having just emailed its human "YOU'RE FIRED", while the human's cardboard box of desk stuff waits on the floor. Drawn entirely in Python with Pillow: fixed geometry, no randomness, no external assets, so the output is byte-identical on every run.

## Run it

```sh
python3 main.py
```

Writes a 1024x1024 PNG to `/output/entry.png` (47,659 bytes, well under the 1 MiB cap).
